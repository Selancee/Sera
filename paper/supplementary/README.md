# Anonymous supplementary-material outline

This directory describes the intended anonymous supplement.

1. ScorePatch JSON schema and supported operation contracts.
2. Benchmark card, 20 source-score manifest, 120 tasks, gold patches/constraints, and review state.
3. Condition prompts, prompt hashes, provider configuration examples, and cost assumptions.
4. Experiment manifest, raw/normalized outputs, deterministic metrics, statistics, and fixed error taxonomy.
5. Reproduction commands and environment metadata.
6. Additional event-level diffs and failure examples.

The automated anonymous package intentionally omits raw provider responses by default while retaining normalized outputs. A formal release decision must account for provider terms and the submission system's file-size limit.
