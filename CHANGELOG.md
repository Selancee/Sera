# Changelog

All notable release-track changes are documented here. Versions follow semantic
versioning where possible; development suffixes identify pre-release packages.

## [1.0.0-dev.14] - 2026-08-23

### Added

- SoftwareX Original Software Publication manuscript in Markdown, LaTeX v4 structure,
  and line-numbered DOCX review form.
- MIT software license, CFF and CodeMeta citation records, direct-dependency license
  inventory, and deterministic source/manuscript export archives.
- SoftwareX installation, user, API, reproducibility, requirements and submission
  documentation.
- Automated draft/submission readiness verifier and publication-package tests.
- Source-adaptive multi-staff playability bounds and asynchronous Composer refinement
  from the preceding dev.14 product milestone.

### Verified

- 120/120 benchmark tasks pass automatic structural/gold/round-trip validation; all
  remain explicitly pending human musical review.
- 360/360 offline fixture experiment cases complete without execution errors and pass
  evidence-drift checks. These are non-formal software checks, not model results.
- 350 Python tests and 108 frontend tests pass; production frontend and packaged
  Windows runtime smoke checks pass.

### Known limitations

- Public repository/tag/archive DOI and author metadata are required before submission.
- Human benchmark review, formal provider comparison and blinded musical-quality study
  are not complete.
- The host-safe path does not claim unrestricted composition or universal MusicXML-host
  compatibility.
